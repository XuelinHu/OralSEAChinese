# 马来西亚中文发音学习系统工作清单

## 1. 项目目标

建设一套面向马来西亚学习者的中文发音学习系统，包含 Android APK、语料管理后台、业务后端、AI 发音评测服务和 PostgreSQL 数据库。

系统第一阶段目标是先跑通完整业务闭环：学习者在 APK 中学习和录音，后端保存练习数据，AI 服务返回发音评分，后台可以管理语料和查看练习记录。

## 2. 当前技术划分

| 模块 | 技术方向 | 目录 |
| --- | --- | --- |
| Android APK | Flutter / Dart | `apk_flutter/` |
| 业务后端 | Node.js | `backend_node/` |
| AI 发音评测服务 | Python FastAPI | `ai_fastapi_postgresql/fastapi_service/` |
| 数据库 | PostgreSQL | `ai_fastapi_postgresql/database/` |
| 项目文档 | Markdown | `docs/`、`DOS/` |

## 4. 建议开发顺序

1. 先定需求范围。
2. 再定数据库表结构。
3. 然后设计接口。
4. 初始化 Node.js 后端和 PostgreSQL。
5. 初始化 FastAPI AI 服务。
6. 初始化 Flutter APK。
7. 先跑通登录、课程、录音上传、评分返回这一条主流程。
8. 再补后台管理、标注和模型训练功能。

## 5. 当前需要讨论的问题

1. APK 第一版是否只做 Android，不考虑 iOS？
2. 后台管理系统是否也放在 `backend_node/` 下，还是单独新建前端目录？
3. Node.js 后端使用 NestJS 还是 Express？
4. PostgreSQL 是否已经有服务器地址、端口、数据库名？
5. AI 第一版是先做模拟评分，还是直接接入真实语音识别或发音评测模型？
6. 标准发音音频由谁提供，是人工上传还是后续自动生成？
7. 学习内容第一版是拼音为主，还是词语、句子也一起做？
8. 后台是否需要教师账号和管理员账号两种权限？
