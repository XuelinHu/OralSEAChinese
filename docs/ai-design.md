# AI 发音评测设计

## 第一版策略

第一版使用 `mock-v1` 规则占位评分，不执行真实语音识别或模型推理。这样可以先验证 APK、Node 后端、FastAPI 服务和数据库设计之间的完整链路。

## 评分字段

- `overall_score`：总分。
- `accuracy_score`：准确度。
- `fluency_score`：流利度。
- `tone_score`：声调分。
- `feedback`：反馈说明。

## 后续模型方向

- 接入 ASR，判断朗读文本是否完整。
- 引入音素或音节级别对齐。
- 增加声调识别，重点评估马来西亚学习者常见声调问题。
- 积累人工标注数据后训练发音评分模型。
