# 需求说明

## 第一版范围

第一版目标是跑通学习者发音练习主流程：获取课程语料、选择拼音/词语/句子、提交录音、获得 AI 发音评分。

## 用户角色

- 学习者：使用 APK 学习中文发音，完成录音练习并查看评分。
- 管理员：维护课程、语料、标准音频、用户与评分记录。
- 教师：查看学习者练习情况，参与语料标注。
- 研究人员：导出语料和标注数据，用于模型训练。

## 核心功能

- APK 支持拼音、词语、句子三类发音练习。
- 业务后端提供认证、课程、语料、练习和评分接口。
- FastAPI 服务提供发音评测接口。
- PostgreSQL 保存课程、语料、音频、练习、评分、标注和模型任务。

## 暂不纳入第一版

- 真实用户权限体系的完整后台页面。
- 真实发音评测模型训练。
- 对象存储、分布式部署和生产级监控。
